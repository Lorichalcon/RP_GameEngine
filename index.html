🎤 音声入力 (STT)

マイクで喋ると無音区間を自動検出してチャット入力欄に文字が入ります（ハンズフリー連続）。手入力の代わりに使えます。

KoboldCpp に Whisper モデルをロードすると OpenAI 互換の /v1/audio/transcriptions が使えます。standalone の whisper.cpp server も可
この時間だけ無音が続くと1区切りとして認識処理。短いほど反応が速いが途中で切れやすい（Web Speech ではエンジンが自動判定）
OFF（既定）: 入力欄に挿入のみ。確認して手動送信。ON: 区切りごとに自動でAIへ送信

💡 使い方:
・チャット欄の 🎤 ボタンで開始/停止（ハンズフリー連続）
・喋る → 灰色で認識途中が表示 → 無音で確定 → 入力欄に追記
⚠️ マイクは https または localhost でのみ動作。スマホから LAN（http://192.168.x.x）で使う場合は Vite を https 起動する必要があります（PC の localhost なら設定不要）

🌍 完全自由空間モード (Free World Mode)

「キャラぷ」の完全自由空間に着想を得た 4 機能セット。シミュレーション型 RP 向け。
親トグルが OFF の場合、サブ設定はすべて無視されます。

プレイヤーが過剰に強くなるのを抑制。原作住人より弱いか同等として扱う
ON にすると Mary Sue 防止トグルの状態に関係なく、無双・最強キャラ演出を許可します。「最初から最強でやりたい」プレイ向け。
緊張・疲労・経験不足を行動結果に反映。「思い通りにならないもどかしさ」を演出
Party Setup の空スロットに ➕ Generate NPC ボタンが出現。LLM が世界観に合う NPC を生成
ユーザー操作なしでも世界が動く。LLM を背景で呼ぶため API コール頻度に注意
初回のテンプレ入力（#世界観 / #user設定 / #初期状況）に対し、AI が世界観の理解度・確認事項を返してから本編開始。原作にない独自能力や設定ズレを早期発見
60〜600 秒。短いほど API コール増加。推奨 300（5分）
クエストの additional_settings が優先。空欄なら「現代日本の日常」

🔍 Web Search

ロールプレイ中の事実確認・最新情報取得用。AI が裏で検索し system prompt に注入。
RP の没入感を保ったまま、最新情報・実在の場所・作品設定などを補強します。

tavily.com で月1000回無料。LLM向け要約済み結果が返るため精度高い
「最新の」「ニュース」「〜って何」等で自動検索。OFF 時は [search:〜] と 🔍 ボタンのみ
連続検索の最低間隔。同一クエリは1時間キャッシュ

💡 使い方:
・チャット欄の 🔍 ボタンで次回送信を強制検索
・メッセージ内に [search:クエリ] を含めると明示検索（RP本文中に埋め込んでもOK）
・自動判定 ON なら「最新のニュース教えて」等で勝手に発動

📝 AI Memo (継続記憶)

AI が応答内に [MEMO: 内容] タグを書くと、自動的にこのメモに追加されます（タグ自体はユーザー表示時には除去）。
メモは次回以降の system prompt に注入され、AI が継続的に参照します。検索結果の核心・NPC の素性・伏線などの長期記憶に最適。

💡 使い方:
・AI 応答に [MEMO: ハルは元教師] のように書くと自動保存
・直近 30 件が system prompt に注入される（上限 200 件、古いものから削除）
・Web Search ON 時は、AI に「重要情報を [MEMO:] で記録せよ」と自動指示

🎭 ペルソナ・モード

{{user}}（プレイヤー）が同一人物のまま複数の顔を使い分ける場合の AI 混同対策。
呼称・一人称（私／僕など）でペルソナを自動判別し、AI が顔の違いを理解して応答します。
※「別キャラへの完全切替」は自動で別人として扱われます（この機能とは別系統）。

空欄でも動作します（AI が一人称・呼称から自動推測）。書いておくと精度が上がります

📋 適用される 4 ルール（system prompt に自動注入）:
① 一人称・呼称で自動判別 — 私／僕、キャラへの呼び方の変化でペルソナ切替を検知
② 1メッセージ内はペルソナ固定 — 途中で呼び方が変わっても冒頭のペルソナを維持（混乱防止）
③ 地の文トーン統一 — 差はセリフ・態度に留め、ナレーションの文体は一定
④ 明示タグ優先 — [春姉さん] おはよう のように冒頭で書けば確実

👥 NPC 発言保証

複数 NPC がいるとき、行動シーンで脇の NPC が棒立ち・無視されるのを防ぎます。
全員ではなくシーン中心の数人だけに最低一言を促すため、コンテキスト負荷は最小限。最大20人編成でも安全。

複数キャラ構成（2人以上）のときのみ実効。掛け合い（Banter）モードでは無効
1〜6人。少ないほどコンテキスト軽量・テンポ重視。多いほど賑やかだが重い（推奨 2〜3）

💡 仕組み: 「登録NPCは全員出さなくてよい。シーンに関わる最大N人だけ最低一言喋らせ、無関係なNPCは登場も言及もしない」と AI に指示します。
これにより20人いても毎ターン重くならず、かつ目の前の数人が無言になる問題も防げます。
